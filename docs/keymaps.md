
# Keymaps Reference

Leader key: **`<Space>`**

---

## File & Project Navigation

| Keymap | Mode | Action |
|---|---|---|
| `<leader>ff` | n | Fuzzy find files (project + history) |
| `<leader>fR` | n | Search files across all disk roots |
| `<leader>fD` | n | Browse directories across all disk roots |
| `<leader>fd` | n | Directory history picker |
| `<leader>e` | n | File explorer toggle (Snacks) |
| `<leader>fb` | n | Open buffers picker |
| `<leader>sg` | n | Live grep in project |
| `L` | n | Next buffer |
| `H` | n | Previous buffer |
| `<leader>q` | n, t | Close buffer or terminal |

---

## Terminal

| Keymap | Mode | Action |
|---|---|---|
| `<leader>tt` | n, t | Toggle floating terminal (Snacks) |

---

## Windows

| Keymap | Mode | Action |
|---|---|---|
| `<A-h>` | n, i, t | Move to left window |
| `<A-j>` | n, i, t | Move to bottom window |
| `<A-k>` | n, i, t | Move to top window |
| `<A-l>` | n, i, t | Move to right window |

---

## Editing

| Keymap | Mode | Action |
|---|---|---|
| `<C-a>` | n, i, v, x, s | Select all file |
| `<leader>/` | n | Comment line |
| `<leader>/` | v | Comment selection |
| `s` | n, x, o | Leap motion (current window) |
| `S` | n | Leap to another window |

---

## LSP & Code

| Keymap | Mode | Action |
|---|---|---|
| `<leader>fm` | n | Format buffer (LSP) |

---

## Compilation

| Keymap | Mode | Action |
|---|---|---|
| `<F5>` | n | Compile & Run current file |
| `<F6>` | n | Compile only |

Supported: `.c`, `.cpp`, `.asm`, `.py`
